2. chown
1. chown swati hello.js  //Changes the owner of hello.js to the user swati  => chown user file
2. chown swati:devs hello.js  //Changes owner to swati and the group to devs  => chown user:group file
3. chown :devs hello.js  //Leaves the owner unchanged but changes the group to devs  => chown :group file
4. chown -r swati project/  //swati as the owner of the folder (files and subfolders)  => chown -r user folder/

Questions:
1. You have a file with permissions -rw-r--r--, and you run chmod +x file.sh. What happens?

Ans : Adds Execute permissions for all (-rwxr-xr-x)

2. What is the difference between chmod 744 file.txt and chmod u=rwx,go=r file.txt?

Ans : Both are same level of permission

3. What is the sticky bit, and when should you use it?

Ans : It is a special permission set on files and directories to restrict the deletion and renaming the file.
Only owner and root user can perform those changes on file/directory with sticky bit

4. You are told to give the owner full access, group only execute, and others no permissions. What symbolic command achieves this?

Ans : chmod 710 file.sh (or) chmod u=rwx,g=x,o= file.sh

5. What is umask, and why is it important?

Ans : It is used for setting default permissions for files and directories. 
    It helps in maintining security level which creation of file or directory.

6. If the umask is 022, what are the default permissions for a new file and a new directory?

Ans : file : 644
      folder : 755

7. Why is umask often set to 002 in development environments but 027 or 077 in production?
Ans :   In development environment, owner and group member has permission to read and write the files.
        But in production, for minimizing the risk of unauthorizied access, 
        only owner is provided with the permission to read and write, 
        group may or may not have permission to read and others have no-permission.

8. useradd vs adduser
Ans :   useradd just creates a user profile.
        adduser is an interactive way for creating user profile and also it creates home 
            directory for the user automatically.
